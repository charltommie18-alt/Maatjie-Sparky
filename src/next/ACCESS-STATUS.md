# Adult access foundation

`adultAccess.js` is an isolated fail-closed authorization boundary. It is not mounted or enabled and does not provide authentication, accounts, identity or age verification, sessions, a database, or a real rate limiter. It must only receive data from real trusted backend verifiers. Session authentication must verify the credential, account state, expiry and revocation on every request. Adult eligibility must be established by a real independent age-verification process and retrieved for the authenticated subject from trusted storage; a checkbox, date entered in a form, or request claims are not proof. Both records require explicit non-revoked state and expiry. The eligibility check is bound to the session subject. Provider and authorization failures deny.

Before connecting this authorizer to the AI route: select and configure a real authentication provider, an appropriate independent 18+ verification approach and protected server-side storage; implement CSRF, shared rate limiting, size limits, privacy, retention and deletion, audit controls, and exercise integration/security tests including revoked/expired sessions and eligibility. Review applicable South African privacy laws and provider terms. Do not collect unnecessary identity documents. Live provider calls and the full application build have not been verified.
