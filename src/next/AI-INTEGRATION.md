# Slim Maat AI integration status

The HTTP adapter in chatRoute.js wires the chat service to the server-side Gemini SDK, but is deliberately not mounted or enabled. The current preview still uses a fixed mock response. No live API call has been verified. Do not publish or mount until real authentication and server-side adult eligibility verification, CSRF protection, a shared abuse-resistant rate limiter, a bounded JSON parser, and a fixed trusted HTTPS origin are configured and tested. Never rely on a client age checkbox. Instantiate the SDK using a secret held only in server environment variables; do not place credentials in the repository or client. The caller must supply the model and implement authorize(request) and limitRequest(request), both returning true only on verified success. Model availability, quota, provider privacy terms and safety behavior must be checked before activation. No WhatsApp messages are automatically read or sent.
